# Veila Technologies — Official Website

> Built by Priya Dharshini as part of the Full Stack Developer hiring evaluation at Veila Technologies.

## 🚀 Tech Stack
- **React 18** — Component-based UI
- **Framer Motion** — Animations & transitions
- **CSS3** — Custom design system with CSS variables
- **Google Fonts** — Syne (display) + DM Sans (body)

## ✨ Features
- **7 Sections**: Hero, About, Services, Why Us, Careers, Contact, Footer
- **Fully Responsive**: Mobile, Tablet, Desktop
- **Smooth Animations**: Scroll-triggered reveals, hover effects, floating elements
- **Interactive Contact Form**: Opens mail client with pre-filled content
- **Job Listings**: Current openings with apply-by-email functionality
- **Modern Design System**: Dark theme with cyan/teal accent palette
- **Performance Optimized**: CSS-only backgrounds, minimal JS, lazy animations

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```
